## 1️⃣ Define Probability
📌 **Probability** is a measure of how likely an event is to occur.

📐 **Formula:**
```
Probability = Favorable Outcomes / Total Outcomes
```

### 📊 Figure 1: Likelihood Scale
```
Impossible ── Unlikely ── Likely ── Certain
   0            0.5              1
```

---

## 2️⃣ Range of Probability Values

✅ Probability values always lie between:

```
0 ≤ P(Event) ≤ 1
```

- 0 → Impossible event ❌
- 1 → Certain event ✅

## 5️⃣ Sample Space

📌 **Definition:**
The set of all possible outcomes of an experiment.

🎲 **Example (Coin Toss):**
```
S = {H, T}
```

---

## 6️⃣ Event & Its Types

📌 **Event:** A subset of the sample space.

🧩 **Types:**
- Simple Event
- Compound Event
- Impossible Event
- Certain Event

---

## 7️⃣ Favorable & Total Outcomes

- **Favorable Outcomes:** Outcomes that satisfy the event
- **Total Outcomes:** All possible outcomes

```
P(Event) = Favorable / Total
```

---

## 8️⃣ Independent & Dependent Events

📌 **Independent:** One event does not affect the other
📌 **Dependent:** One event affects the other

🎯 **Example:**
- Tossing two coins → Independent
- Drawing cards without replacement → Dependent

---

## 9️⃣ Mutually Exclusive Events

📌 Events that **cannot occur at the same time**.

```
Example: Head and Tail in a single toss
```

## 1️⃣1️⃣ Probability of Even Number (Dice)

🎲 Even numbers = {2, 4, 6}

```
P(Even) = 3 / 6 = 1 / 2
```

---

## 1️⃣2️⃣ Probability of Drawing a Red Card

🂡 Red cards = 26, Total cards = 52

```
P(Red) = 26 / 52 = 1 / 2
```

---

## 1️⃣3️⃣ Probability of Picking a Red Ball

🎯 Bag contains 4 red, 6 blue balls

```
P(Red) = 4 / 10 = 0.4
```

## 1️⃣5️⃣ Empirical Probability

📌 **Definition:**
Probability based on **observed data or experiments**.

📐 **Formula:**
```
Empirical Probability = Observed Frequency / Total Trials
```

📊 **Example:** Rain occurred 20 days in 100 days → P = 0.2

---

## 1️⃣6️⃣ Theoretical Probability

📌 **Definition:**
Probability calculated using **mathematical reasoning**.

🎲 Example:
```
P(Head) = 1 / 2
```

---

## 1️⃣7️⃣ When Empirical Probability is More Useful

✨ When:
- Real‑world data is available
- Outcomes are unpredictable
- Theoretical assumptions fail

📊 Example: Stock market trends
