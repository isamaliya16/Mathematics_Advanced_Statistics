## 1️⃣ Types of Statistics
📌 **Statistics is broadly classified into two main types:**

- 🧾 **Descriptive Statistics** – Summarizes and presents data
- 🔮 **Inferential Statistics** – Draws conclusions from samples

### 📊 Figure 1: Classification of Statistics
```
                STATISTICS
                    │
        ┌───────────┴───────────┐
        │                       │
Descriptive Statistics   Inferential Statistics
        │                       │
  Tables, Charts        Estimation, Hypothesis
```

---

## 2️⃣ Descriptive vs Inferential Statistics

### 📊 Figure 2: Comparison Diagram

| Aspect | 🧾 Descriptive Statistics | 🔮 Inferential Statistics |
|------|---------------------------|---------------------------|
| **Purpose** | Summarizes and organizes data in a meaningful way | Draws conclusions and makes predictions |
| **Data Used** | Uses the entire available dataset | Uses a sample to represent a population |
| **Output** | Tables, charts, averages, and summaries | Probabilities, estimates, and hypothesis tests |
| **Scope** | Describes what the data shows | Explains what the data implies about a population |

```
Sample ➜ Analysis ➜ Inference ➜ Decision
```

## 4️⃣ Descriptive Statistics – Meaning & Importance

🧾 **Definition:**
Descriptive Statistics involves methods to **organize, summarize, and present data** in a meaningful way.

✨ **Why it is Important:**
- Makes large datasets easy to understand
- Identifies trends and patterns
- Helps in decision‑making

```
Raw Data ➜ Tables ➜ Charts ➜ Insights
```

## 7️⃣ Mean (Average)

📌 **Definition:**
Mean is the arithmetic average of a dataset.

📐 **Formula:**
```
Mean (μ) = Σx / n
```

### 📊 Figure 3: Mean Representation
```
Data Points: 10   20   30   40   50
                 ↑
               Mean = 30
```

📊 **Use Case:** Suitable for symmetric data without outliers.

---

## 8️⃣ Median

📌 **Definition:**
Median is the middle value after sorting data.

### 📊 Figure 4: Median Position
```
Ordered Data: 5   10   15   20   100
                    ↑
                 Median
```

✅ **Preferred when:** Data contains outliers or skewness.

---

## 9️⃣ Mode

📌 **Definition:**
Mode is the most frequently occurring value.

### 📊 Figure 5: Mode Frequency
```
Values: A  B  B  C  B  D
             ↑
           Mode = B
```

🎯 **Best for:** Categorical and discrete data.

---

## 🔟 Range

📌 **Definition:**
Range measures the spread between max and min values.

📐 **Formula:**
```
Range = Maximum − Minimum
```

### 📊 Figure 6: Range Visualization
```
Min ------------------------- Max
 10                           90
```

📊 **Indicates:** Overall data spread.

---

## 1️⃣1️⃣ Variance

📌 **Definition:**
Variance measures the average squared deviation from the mean.

📐 **Formula:**
```
σ² = Σ(x − μ)² / n
```

### 📊 Figure 7: Variance Concept
```
Low Variance  : ●●●●● (close to mean)
High Variance : ●   ●     ●
```

✨ **Significance:** Indicates data consistency.

---

## 1️⃣2️⃣ Standard Deviation

📌 **Definition:**
Standard Deviation is the square root of variance.

📐 **Formula:**
```
σ = √Variance
```

### 📊 Figure 8: Standard Deviation Spread
```
Mean
  │
  │   ● ● ●
  │ ●         ●
  └────────────────
```

📊 **Importance:**
- Easy to interpret
- Used in finance, quality control, and data science
