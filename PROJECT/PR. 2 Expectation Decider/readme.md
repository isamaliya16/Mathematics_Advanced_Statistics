# 📊 Student Performance Probability Analysis (Expectation Decider)🎓📈

---

## ✨ Project Overview
This project presents a **complete probability & statistical analysis** of student performance data.  
It explores how **study habits, attendance, and group discussion participation** influence the probability of **passing the final exam**, using real-world data and Python-based analysis.

The project combines **theoretical concepts** with **practical implementation**, making it ideal for academic submission and portfolio presentation.

---

## 🎯 Project Objectives
✔ Understand core probability concepts  
✔ Apply empirical & theoretical probability  
✔ Model outcomes using random variables  
✔ Analyze relationships using contingency tables  
✔ Visualize data using Venn diagrams  
✔ Apply Bayes’ Theorem for prediction  
✔ Interpret results in real-world context  

---

## 🗂 Dataset Description 📁
The dataset contains **500 student records** with the following attributes:

| 🔑 Column | 📖 Description |
|---------|---------------|
| `study_hours` | Weekly study hours |
| `attendance` | Attendance percentage |
| `group_discussion` | Participation (Yes / No) |
| `previous_test_score` | Previous exam score |
| `final_exam_pass` | Final result (Pass / Fail) |

## 📌 Analysis Breakdown 📝

### 1️⃣ Understanding Probability
- Explained probability fundamentals
- Identified real events from dataset

### 2️⃣ Types of Probability
- ✔ Empirical Probability (from data)
- ✔ Theoretical Probability (using models)

### 3️⃣ Random Variable & Probability Distribution
- Defined random variable: number of passes out of 3 students
- Used **Binomial Distribution**
- Calculated **mean and variance**

### 4️⃣ Venn Diagram Visualization
- Study hours > 10/week
- Attendance > 80%
- Overlap showing disciplined students

### 5️⃣ Contingency Table Analysis
- Group Discussion vs Final Exam Result
- Calculated:
  - 🔗 Joint Probability
  - 📉 Marginal Probability
  - ➡ Conditional Probability

### 6️⃣ Relationship Interpretation
- Events are **dependent**
- Not mutually exclusive
- Participation improves performance

### 7️⃣ Bayes’ Theorem Application
- Calculated probability of passing given high attendance
- Demonstrated attendance as a **strong success predictor**
